**Ваши серверы. Ваши маршруты. Один понятный клиент для Windows.**

## Быстрый старт

1. [Скачайте последний выпуск](https://github.com/spikeefimov-gif/NNLINK-releases/releases/latest): установщик или portable-версию для Windows x64.
2. Откройте «Подписки» и добавьте **свою** ссылку Clash/Mihomo либо импортируйте файл. Если провайдер требует HWID, включите его передачу именно для этой подписки.
3. В разделе «Серверы» выберите узел. На главной странице выберите **TUN** для системного подключения или **Прокси** для программ, использующих прокси, затем нажмите «Подключить».
4. Если нужен выборочный маршрут, откройте «Правила» и переключитесь с «Всё через VPN» на «По правилам».

Нет соединения? В настройках откройте **«Проверить соединение»**: приложение последовательно проверяет ядро, подписку, сеть, DNS и доступ к серверу.

## Что такое NNLINK

NNLINK объединяет повседневные задачи сетевого клиента в одном окне: добавление источников, выбор сервера, подключение, правила для приложений и сайтов, настройку DNS и диагностику. Можно подключить весь компьютер или направить через сервер только нужный трафик.

Интерфейс NNLINK работает поверх **Mihomo** — сетевого ядра, которое обрабатывает конфигурации, соединения и маршрутизацию. Приложение управляет им через разделы «Главная», «Серверы», «Правила», «Подписки» и «Настройки». Знать команды Mihomo для обычного использования не требуется.

### Какие протоколы понимает ядро

Mihomo принимает узлы этих типов в совместимой конфигурации:

| Группа | Протоколы |
| --- | --- |
| Современные прокси | **VLESS, VMess, Trojan** |
| Шифрованные прокси | **Shadowsocks (SS), ShadowsocksR (SSR)** |
| UDP/QUIC | **Hysteria, Hysteria 2, TUIC** |
| Туннельные конфигурации | **WireGuard, AmneziaWG 3.1** |
| Классические прокси | **SOCKS5, HTTP** |

Это типы узлов, распознаваемых ядром, а не список серверов, которые выдаёт NNLINK. Для подключения нужен действующий профиль с параметрами вашего сервера. Конфигурацию **AmneziaWG 3.1** можно импортировать из `.conf` или из YAML/JSON-профиля с `amnezia-wg-option`.

## Как направлять трафик

В NNLINK есть два независимых выбора: **как Windows передаёт трафик приложению** и **по каким правилам он идёт через сервер**.

| Способ подключения | Когда выбрать |
| --- | --- |
| **TUN** | Для подключения на уровне системы: браузеры, игры и программы не нужно по отдельности настраивать на прокси. Для создания туннеля нужны права администратора. |
| **Системный прокси (System Proxy)** | Когда нужен прокси без системного туннеля. Работает для программ, использующих настройки прокси Windows; другие приложения можно вручную направить на локальный HTTP/SOCKS-адрес из настроек NNLINK. |

TUN и системный прокси — альтернативные способы подключения, одновременно их включать не нужно.

| Маршрутизация | Что происходит |
| --- | --- |
| **Всё через VPN** | Трафик направляется через выбранный сервер. Подходит для простого первого запуска. |
| **По правилам** | Для программ, доменов и IP-адресов задаются отдельные действия: через VPN или напрямую. То, что не совпало с правилом, идёт напрямую. |

**Пример:** отправить браузер через VPN, а игру оставить на прямом соединении. Для этого выберите «По правилам» и добавьте правило для программы или нужных доменов. Доступны правила по имени процесса, домену или его части, GeoSite, GeoIP и IP-CIDR; для VPN-правила можно указать конкретный сервер.

## Подписки, профили и серверы

- **Ссылка от провайдера.** Добавьте HTTP/HTTPS-ссылку на конфигурацию Clash/Mihomo в разделе «Подписки». Приложение загрузит профиль и покажет доступные в нём серверы. Подписку можно обновлять.
- **Локальный файл.** Импортируйте `.yaml`, `.yml`, `.json` или WireGuard/AmneziaWG `.conf`.
- **Выбор сервера.** Откройте «Серверы», найдите нужный узел и добавьте часто используемые в избранное.
- **HWID под вашим контролем.** Передача идентификатора устройства выключена по умолчанию. Если провайдер требует его, включите галочку только для нужной подписки.

Одиночные ссылки вида `vless://` и `trojan://` не заменяют подписку Clash/Mihomo: используйте совместимый профиль или файл конфигурации.

## Настройки под себя

| Раздел | Что можно настроить |
| --- | --- |
| **Внешний вид** | Светлая, тёмная и OLED-темы, прозрачность, акцентный цвет и вид окна. |
| **Сеть и DNS** | TUN или системный прокси, DNS-режим, отдельная настройка AI-DNS, доступ из локальной сети. |
| **Подключение** | Автопереподключение, Kill Switch, автоподключение при запуске. |
| **Поведение Windows** | Автозапуск, запуск в трее, сворачивание при закрытии и горячие клавиши. |
| **Данные и диагностика** | Резервная копия настроек, журнал, активные соединения, статистика трафика и проверка подключения. |

AI-DNS — дополнительная настройка DNS для отдельных AI-сервисов, а не отдельный VPN-режим. Kill Switch предназначен для блокировки сети при неожиданном разрыве туннеля; включайте его осознанно, если вам подходит такое поведение.

## Частые вопросы

**Нужна ли регистрация?** Нет. Нужна только ваша рабочая подписка или конфигурация.

**Почему серверов нет?** NNLINK не продаёт и не раздаёт серверы. Добавьте свой источник в «Подписках» и проверьте, что он содержит узлы.

**TUN или прокси?** Для обычного подключения всего компьютера начните с TUN. Если нужны только приложения, поддерживающие прокси, используйте системный прокси или локальный HTTP/SOCKS-адрес.

**Что делать, если подписка не добавляется?** Проверьте ссылку, доступ к ней без VPN и формат ответа провайдера. Если он требует HWID, включите галочку для этой подписки и повторите попытку.

**Можно ли оставить часть трафика без VPN?** Да. Выберите режим «По правилам» и задайте нужным программам, доменам или IP действие «Через VPN» либо «Напрямую».

**Что такое AmneziaWG 3.1?** Это параметры соединения WireGuard/AmneziaWG. NNLINK понимает соответствующий `.conf` и записи `amnezia-wg-option` в совместимом профиле.
