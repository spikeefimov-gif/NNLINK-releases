# NNLINK

### Сеть под вашим контролем

Самостоятельный клиент для Windows: ваши конфигурации, ваши серверы, ваши правила. Без обязательного аккаунта и привязки к одному провайдеру.

</div>

![Главный экран NNLINK](images/home.png)

## Скачать

**[NNLINK 1.0.0 — выпуск для Windows](https://github.com/spikeefimov-gif/NNLINK-releases/releases/tag/v1.0.0)**

- `NNLINK-Setup-1.0.0.exe` — установка на компьютер.
- `NNLINK-Portable-1.0.0.exe` — запуск без установки.
- `SHA256SUMS.txt` — контрольные суммы файлов.

Для работы нужен собственный профиль или ссылка на подписку. Приложение не продаёт и не выдаёт VPN-доступ.

Если хотите поддержать развитие клиента: **[добровольный донат](https://pay.cloudtips.ru/p/9e6c8a09)**.

## Простое управление сетью

| Подписки и профили | Серверы и правила | Оформление |
| --- | --- | --- |
| Добавление ссылки или файла конфигурации. HWID выключен по умолчанию и настраивается для каждого источника. | Отдельные разделы для выбора сервера, избранного и собственных правил. | Тёмная, светлая и OLED-темы, прозрачность и компактное окно. |

Поддерживается импорт конфигураций **AmneziaWG 3.1**: файлы `.conf` и профили YAML/JSON с параметрами `amnezia-wg-option`.

## Локальные данные

Настройки, профили и журнал NNLINK находятся в `%APPDATA%\NNLINK`. Приложение не требует аккаунта NNLINK и не предоставляет собственные VPN-серверы. Ссылки подписок и конфигурации могут содержать ключи доступа — не прикладывайте их к публичным обращениям.

## Сторонние компоненты

Сетевое ядро основано на Mihomo и распространяется по GPLv3. [Соответствующие исходники ядра](https://github.com/spikeefimov-gif/NNLINK-releases/releases/download/v1.0.0/NNLINK-Core-Source-1.0.0.zip) с зависимостями для офлайн-сборки доступны рядом с файлами выпуска. Исходники Electron-интерфейса в этот архив не входят. Права на другие сторонние компоненты определяются их собственными лицензиями; название и оформление NNLINK относятся к клиентскому приложению.
