# NNLINK 1.0.0

Первый выпуск самостоятельного клиента для Windows. Добавьте собственную ссылку подписки или импортируйте файл конфигурации, выберите сервер и режим подключения.

В приложении доступны разделы серверов, правил, подписок и настроек. Передача HWID для подписки выключена по умолчанию и включается отдельно для каждого источника. Настройки, профили и журнал хранятся в `%APPDATA%\NNLINK`.

Поддерживается импорт конфигураций **AmneziaWG 3.1**: `.conf` с параметрами v3.1 и профилей YAML/JSON с `amnezia-wg-option`.

## Файлы выпуска

- `NNLINK-Setup-1.0.0.exe` — установщик Windows.
- `NNLINK-Portable-1.0.0.exe` — portable-версия.
- `latest.yml` и `NNLINK-Setup-1.0.0.exe.blockmap` — метаданные обновления приложения.
- `NNLINK-Core-Source-1.0.0.zip` — соответствующие исходники GPLv3-ядра, включая зависимости для офлайн-сборки. Код Electron-интерфейса в архив не входит.
- `SHA256SUMS.txt` — контрольные суммы скачиваемых файлов.

Файлы приложения пока не подписаны сертификатом издателя, поэтому Windows может показать предупреждение SmartScreen. Скачивайте NNLINK только с этой страницы и сверяйте SHA-256 перед запуском.
